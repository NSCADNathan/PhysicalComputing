# Course Overview

This course is an introduction to the fundamentals of electricity and electronics as they pertain to art. Students will learn how to design and build electronic circuits for various applications, including sensing motion, touch, sound, and other environmental conditions, as well as controlling lights, motors, and other actuators.

Emphasis will be placed on creating emergent and interactive sculptural, installation, performance, video, and audio works for creative, critical, and social purposes.

Practical workshops will revolve predominantly around accessible Arduino AVRs and inexpensive sensors, motors, lights, speakers, and other I/O components.

# Learning Outcomes

Upon successful completion of this course the student will demonstrate the ability to:

  1. Basic Electronics Literacy:
    • Understand terminology and usage of basic components
    • Understand constraints when building circuits
  2. Documentation Skills: Document work using concise descriptions, code snippets and standardized circuit diagrams
  3. Artistic Expression: Create artistic expression with electronics as a fundamental element

# Course Structure
